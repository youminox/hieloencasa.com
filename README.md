# HieloEnCasa.com 🧊

Guía especializada en español para elegir **máquinas de hielo de sobremesa en Amazon Estados Unidos (`amazon.com`)**, comparando modelos de **cubitos (bala y cubo cuadrado cristalino)** y de **hielo tipo nugget (masticable / *sonic ice*)** según su **precio, capacidad (`lb/24h`), tamaño bajo gabinete y nivel de ruido (`dB`)** para **uso diario** o **reuniones en casa**.

- **Dominio:** `https://hieloencasa.com`
- **Repositorio:** `https://github.com/youminox/hieloencasa.com.git`
- **Stack:** Next.js 16 App Router (100 % SSG estático), Tailwind CSS v4, GSAP + Lenis, Supabase Edge Functions (`hieloencasa-chat` con `gpt-4o-mini` predeterminado + `hieloencasa-images` con `gpt-image-1` calidad media `< 100 KB`).
- **Contenido sin canibalización:** 1,140 URLs estáticas (800 artículos SEO informacionales + 320 artículos transaccionales Amazon + 12 hubs pilares + Home de 15 secciones + 7 páginas legales).
- **IDs de Afiliados Amazon:** `hieloencasa-20` (Amazon EE. UU.) / `hieloencasa-21` (Amazon España).
